ocrb10.otf — OCR-B outline font, from CTAN: https://ctan.org/pkg/ocr-b-outline
Original METAFONT sources by Norbert Schwarz; outlines by Z. Wagner.
License (from the package README): "you may freely use, modify, and/or
distribute any of these files, without limitation."

ocrb.js embeds the same font as base64 so it also works when index.html is
opened via file:// and inside exported SVG/PNG files.

opensans.js — Open Sans Regular (https://github.com/googlefonts/opensans), only printable ASCII,
as base64 WOFF2 (about 12 KB). License: SIL Open Font License 1.1 (OFL-OpenSans.txt), which allows
embedding and redistribution. Embedded the same way as OCR-B, so it shows the same on every device
and travels inside exported SVG files.
